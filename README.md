# 🌧️ make.it.rain
Watch every word fall apart. 

## ⋆｡°• ⛆ What it Does
- Splits all visible text into individual letters
- Animates each letter to fall down the screen and fade out
- Random delays and speeds for natural, chaotic motion
- Loops forever, just like your unread emails

## 📦 Installation
1. Clone or download this repo
2. Go to `chrome://extensions/` in your browser
3. Enable "Developer mode" (top right)
4. Click "Load unpacked" and select this extension's folder
5. Reload any tab and enjoy the downpour
